# Development reference artwork

The WebP files here are temporary crops from the Nova Launcher design references
supplied for Development Task 01. They illustrate fixture games and are not
downloaded from a Roblox API. All artwork is bundled locally.

Reference artwork is excluded from the repository's MIT license. Game names,
characters, and underlying artwork belong to their respective owners. Permission
to redistribute these assets has not been established. Replace them with
authorized assets before distributing a release.
